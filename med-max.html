MED-MAX

함께 복약을 이어가는 작은 공동체
약꾹은 MED-MAX 팀이 장기 복약의 고립감과 동기 저하를 다룬 Tech for Impact 프로젝트입니다. 사용자가 같은 공간에 들어가 서로의 움직임을 볼 수 있게 클라이언트와 서버를 연결했습니다.

기간
2024.08 – 2024.12
담당
Unity 클라이언트·UI와 멀티유저 연동
도구·방법
Unity 2D, WebSocket, HTTP, React Native

매일 접속하는 환자와 답변하는 약사

팀은 장기 복약자가 서로 지지하고 약사에게 질문할 수 있는 서비스를 구상했습니다. 약사가 채팅방에 늘 머물러야 하는 부담을 고려해, 환자들은 공동 목표를 가진 2D 공간에서 만나고 약사는 편지형 Q&A에 비동기로 답하는 구조를 설계했습니다.

같은 공간에서 움직이도록

저는 Unity 클라이언트와 UI에서 로그인·입력 검증·화면 전환을 사용자 공간에 연결했습니다. 다른 사용자의 위치와 이동 상태는 WebSocket으로 동기화하고, 사용자·복약 정보는 HTTP로 받아 화면에 반영했습니다.

팀의 통합 결과

팀은 Unity WebGL 공간을 React Native 앱의 WebView에 연결하고 방 ID를 기준으로 사용자를 같은 공간에 배정했습니다. 이 프로젝트로 팀이 Tech for Impact 사회가치상을 받았습니다. 실제 사용자의 복약 지속 효과 측정은 후속 과제입니다.
