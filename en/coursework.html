Systems Programming and Testing

Fall 2026 · Rust · KAIST CS330

Virtual Memory in KeOS

Allocating physical memory as soon as a process requests an address range reserves pages it may never touch. In KeOS, I implemented a page-fault handler that allocates a physical page on first access.

After a fork, parent and child share a page until one writes to it. I implemented that copy-on-write path and checked it alongside lazy allocation in a project test suite of 38 passing tests.

Fall 2026 · C · gcov · GNU grep 2.0

Testing Branches in GNU grep

I tested successful matches, searches with no match and command errors in GNU grep 2.0. By measuring each input separately with gcov, I could identify tests that reached a previously unvisited branch.

Across 62 inputs, the suite executed 79.52% of executable lines and took 60.48% of branches at least once.

C · Assembly

MIPS-32 and MU0 Assembly Tools

I wrote an assembler that resolves label addresses, parses instructions and operands, and encodes them as machine code. For MU0, I also implemented a simulator so I could follow changes to memory as each instruction ran.

C · TCP sockets

TCP Mini-FTP

I built a client and server in C with commands for uploading files, downloading them and ending a session. Because one TCP read need not contain one complete command, I handled message boundaries explicitly and tracked connection errors separately from file I/O errors.

Scala · Programming languages

KFAE and X-FIBER Interpreters

When a function is called later, where does it find the variables it refers to? I implemented interpreters over abstract syntax trees, using closures to capture a function’s defining environment and continuations to represent the rest of a computation.

Algorithms and Modeling

Spring 2026 · Python · KAIST CS470

Pacman Capture-the-Flag AI

The attacker decides when to stop collecting food and return home before being caught. When the defender cannot see an opponent, it compares the current board with the previous turn and heads toward recently missing food.

The agent averaged a 92.5% win rate across four opponent configurations. A cautious opponent that tracked the attacker was the hardest match, pointing to return-route selection as the next improvement.

Python · NumPy

Classification Models from Scratch

I built logistic regression and a small neural network in NumPy. I implemented backpropagation and Adam, then traced how the gradient changed each parameter. When training stalled, I checked array shapes, weight initialization and gradients.

MATLAB · Computational neuroscience

Simulating Neuron Firing

I simulated Hodgkin–Huxley and leaky integrate-and-fire neurons and varied the input current to study the threshold and frequency of firing. I used autocorrelation and the Fano factor to compare timing patterns and spike-count variability in generated spike trains.

Image Processing and Electronics

Fall 2026 · Computer vision · FFT

Hybrid Images with Spatial and Fourier Filters

I combined the low frequencies of one photograph with the high frequencies of another so that different features stood out at different viewing distances. I implemented the filters with spatial convolution and with the fast Fourier transform (FFT).

Across 80 test conditions, including different filters and padding, the maximum absolute difference between implementations was below 9 × 10⁻¹⁵. On one pair of 361 × 410 RGB images, my local run took 4.35 seconds with spatial convolution and 0.13 seconds with the FFT.

Fall 2026 · LM741 · LM386 · KAIST EE305

Analog Audio Filters and Amplification

I measured the output amplitude of low-pass and high-pass filters with an oscilloscope as I varied the input frequency. I then connected the filters to an LM386 amplifier and a speaker to compare voltage gain with perceived loudness.

The low-pass filter’s measured gain fell at high frequencies, but the listening observations did not follow the same trend throughout the test range. I reported the electrical measurements and the listening results separately.
