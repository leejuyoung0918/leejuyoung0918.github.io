Gut Microbiome and Parkinson’s Disease

From public 16S sequences to a table for machine learning
Do gut microbial communities differ between people with Parkinson’s disease and healthy controls? I selected two public sequencing datasets, inspected the read counts, and built a table for comparing microbial sequence variants across samples.

Dates
Mar – Jun 2025
Data
Gut microbiome 16S rRNA gene sequences
Tools
QIIME 2, DADA2, Docker, Google Colab

Choosing the source data

I looked in the European Nucleotide Archive for studies with paired-end 16S reads and both Parkinson’s and control groups. I selected PRJEB55464 and PRJEB27564. For the second study, I matched forward and reverse files by sequencing run and listed each pair in a manifest for QIIME 2.

From reads to a feature table

Forward read counts ranged from 97 to 361,849 per sample in the second dataset. After checking that spread, I used DADA2 on test data to remove sequencing errors and chimeras. The resulting table recorded how often each distinct amplicon sequence variant (ASV) occurred in each sample. I also inspected the taxonomic assignments for representative sequences.

Resuming an interrupted run

The Colab session ran out of memory during taxonomic classification. I pinned the QIIME 2 version in Docker and saved the output of each stage so I could resume from the last completed step. With the table ready, I explored a random forest for distinguishing the two groups and proposed using SHAP to examine which features contributed to individual predictions.
