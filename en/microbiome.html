Gut Microbiome and Parkinson’s Disease

If the gut and brain communicate, what could the gut microbiome tell us?
Learning about the gut–brain axis made me want to explore alpha-synucleinopathies, neurological conditions associated with the accumulation of alpha-synuclein protein. I narrowed that interest to comparing the gut microbiomes of people with Parkinson’s disease and controls, starting by turning public sequencing reads into a table that could support analysis.

Dates
Mar – Jun 2025
Data
Gut microbiome 16S rRNA gene sequences
Tools
QIIME 2, DADA2, Greengenes, Python, Google Colab
  1. Select datasets
  2. Inspect reads
  3. Build feature table
  4. Assign taxonomy
  5. Plan classification

Turning the question into dataset criteria

I wanted to investigate whether gut microbial patterns could provide clues about the presence or progression of alpha-synucleinopathy. I began with Parkinson’s disease and looked for paired-end 16S rRNA data with case and control labels and clear sample metadata. I selected PRJEB55464 and PRJEB27564 from the European Nucleotide Archive.

Checking the inputs before processing

For PRJEB27564, I paired the forward and reverse files for 300 sequencing runs in a QIIME 2 manifest. The summary showed a wide range of forward read counts, from 97 to 361,849 per run. I inspected the read-count distribution and sequence quality to assess the inputs for subsequent preprocessing.

From raw reads to 880 features

I imported ten test samples from PRJEB55464 into QIIME 2 and ran DADA2 to correct sequencing errors, merge paired reads and remove chimeras. The output counted 880 distinct amplicon sequence variants (ASVs) across those ten samples. This table provides the microbial features for a comparison or classification experiment.

Connecting sequences to microbial groups

The saved taxonomic assignments use a Greengenes classifier. I matched the assignments to the feature table by ASV identifier and aggregated counts by microbial group. About 50.8% of reads lacked a phylum assignment. Keeping that category in the chart makes the limits of the reference data and classifier visible in the interpretation.

Keeping useful outputs when a run stops

A Colab session ran out of memory while classifying representative sequences. I retained intermediate outputs and the QIIME 2 records of inputs, parameters and software versions. I also prepared a Docker execution procedure and code for another reference classifier while exploring ways to resume the analysis with the same inputs.

The classification experiment I proposed

The presentation proposed a random forest to distinguish Parkinson’s cases from controls, followed by SHAP to examine which microbial features contribute to predictions. A subsequent experiment would need correctly matched disease labels and evaluation that accounts for study and collection conditions. The ten-sample result shown here covers preprocessing and construction of the taxonomic feature table.

What the project meant to me

I turned an interest in gut–brain communication into dataset criteria, preprocessing steps, model inputs and questions to test. Understanding each sample’s identity and quality, including the sequences we could not classify, became the starting point for interpreting a relationship with disease. I want to extend this work by looking for features that persist in independent patient groups and examining whether they relate to progression or early changes.
