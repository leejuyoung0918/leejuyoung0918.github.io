읽기 연습 웹앱

읽기 연습까지 이어지는 로그인과 메인 화면
읽기에 어려움을 겪는 사람이 글을 읽고 핵심을 파악하는 연습에 집중할 수 있도록, 로그인부터 메인 화면까지의 흐름을 설계하고 React로 구현했습니다.

시기
2023년 겨울
담당
화면 설계와 프런트엔드 개발
도구
Figma, React, React Router, Firebase Authentication

무엇을 먼저 읽을까

읽기 속도와 글의 요지를 파악하는 능력을 연습하는 웹앱이었습니다. 메뉴와 설명을 이해하는 데도 읽기 노력이 든다는 점이 설계의 제약이었습니다. Figma에서 화면의 정보 순서를 정하고, 사용자가 먼저 볼 내용과 다음 행동을 한눈에 찾도록 로그인 화면과 메인 화면을 구성했습니다.

로그인 화면을 앱에 연결하기

React로 로그인과 메인 페이지를 구현하고 React Router로 화면을 연결했습니다. 로그인 폼에는 Firebase Authentication을 붙여 인증 결과에 따라 로그인 상태를 관리하고, 실패했을 때의 오류도 처리했습니다.

구현하면서 달라진 관점

로그인과 메인 화면을 함께 설계하면서, 사용자가 로그인한 뒤 어디로 가야 할지 이해하는 데 필요한 문구와 이동 단계도 살펴봤습니다. 읽기를 돕는 제품에서는 안내 문구 하나와 화면 전환 하나도 사용자가 읽어야 할 내용의 일부였습니다.
