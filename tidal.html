XR development · XR 개발 인턴

Tidal Adventure

갯벌 탐험에서 다음 행동이 보이도록
Overay의 VR 콘텐츠 개발에 참여해 생물을 가리킬 때의 반응, 다음 구역을 찾는 안내, 생물의 이동을 개선했습니다.

기간
2024.12 – 2025.01
담당
Overay XR 개발 인턴 · 상호작용 개선과 기기 QA
도구·방법
Unity, C#, XR 컨트롤러, Git

가리키는 순간에 피드백 주기

Tidal Adventure에서 사용자는 갯벌을 돌아다니며 생물을 채집합니다. 기존 Unity 프로젝트의 장면과 프리팹, 스크립트 참조를 따라 선택 이벤트와 진동이 발생하는 지점을 찾았습니다. 컨트롤러로 가리킨 생물을 강조하고, 크기 조건에 따라 색을 바꿔 대상의 상태를 바로 확인할 수 있게 했습니다.

다음 구역을 알려주는 손목 나침반

새 구역이 열리면 손목 나침반이 그 방향을 가리키고, 도착하면 안내가 꺼지도록 구현했습니다. 특정 구역 번호에 고정됐던 진행 규칙도 구역 수와 개방 시간 목록으로 계산하도록 바꿨습니다.

실제 기기에서 탐험 흐름 확인

생물이 장애물에 부딪힌 뒤 급하게 방향을 바꾸던 동작에는 전방 충돌 감지와 가감속을 적용했습니다. 선택과 채집, 다음 구역 안내가 차례대로 이어지는지 실제 XR 기기에서 반복 확인했습니다. 변경 사항을 Git 브랜치와 코드리뷰로 공유하고 배포 준비에 참여했습니다.
